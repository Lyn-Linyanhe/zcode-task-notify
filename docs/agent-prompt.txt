帮我在**这台电脑**上装好「ZCode 任务通知」——让 ZCode 的任务完成/出错/需要确认时，自动推送到我的手机企业微信。

仓库：https://github.com/Lyn-Linyanhe/zcode-task-notify
执行手册：仓库根目录的 AGENTS.md（如果你打不开网页，先把仓库 clone 或下载下来再读）

请按 AGENTS.md 里的「A. 安装执行手册」执行，注意：

1. 装到稳定目录（推荐 %USERPROFILE%\.zcode\task-notify），别留在 Downloads；
2. 需要我做的事再问我——比如到手机企业微信里建一个群机器人、复制 webhook 地址给我。
   不要自己编地址，也不要没拿到就假装装好了；
3. 装完跑 python doctor.py 自检（会往群里发一条测试消息，发之前跟我说一声）；
4. 最后告诉我：装在哪、怎么验证、怎么临时静音、怎么卸载。
   另外提醒我「必须新开一个 ZCode 会话才生效」。

我的系统是 Windows。可选功能（AI 摘要、手机批准/拒绝）先不做，等我把基础的通知跑通再说。
