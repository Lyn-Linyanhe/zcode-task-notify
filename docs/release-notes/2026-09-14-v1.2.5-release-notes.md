## 安装体验（本版重点：让朋友也能自己装）

- **双击即装**：新增 `install.bat`——自动检查 Python（"商店空壳"和版本过低都能识别，不合格就自动弹出一份中文安装指引），合格就直接装。文件保持纯 ASCII：cmd.exe 按系统码页解析批处理，中文 `.bat` 在部分机器上会被拆坏（实测踩到）。另用 `.gitattributes` 标记 `*.bat -text`，保证 GitHub 的 **Download ZIP** 解压出来是 CRLF（否则双击可能解析失败）。
- **装完立刻知道通没通**：填了 webhook 就默认往群里发一条「🩺 安装成功」，不用等到下一个任务结束才发现地址填错；`--no-test` 可关。
- **webhook 当场校验**：粘错（少前缀、粘成 Bot ID、粘成别的地址）立刻指出并给出获取路径，最多重问三次；以前会一路静默失败。
- **`--llm-key` 一条命令开启 AI 摘要**，不用再手改 JSON 三个字段。
- **换目录 / 重新下载后重跑一次即可**：以前旧注册认不出来，会变成**两条 hook 同时跑**（一条推送正常、另一条静默失败，现象是"通知时有时无 + 失败日志莫名增多"，极难排查）。现在会自动识别并替换，输出里说明清掉了哪个旧位置。
- **给 agent 的安装手册**：新增 `AGENTS.md`（agent 进仓库会自动读到：终态定义、硬性禁令、故障处置表）与 `docs/agent-prompt.txt`（一段可直接粘贴给 agent 的提示词）。朋友不必解压双击——把提示词丢给电脑上的 agent 就行，唯一需要他自己做的只有去企业微信建群机器人拿地址。README 顶部同时加了「三步装好」与「让 AI 帮你装」。

## 修复

- 文档原写「doctor 必须 16 PASS」，但**未启用手机批准时只输出 14 项**（aibot 那几项合并成一条「未启用」）——按数字判会让 agent 误判失败。改为以 **0 FAIL** 为准并注明两种情况。这是以「朋友 agent」身份实跑手册时抓到的。
- `install.py` 加了 `--no-test` 时，收尾语仍写着「手机上确认已收到」；改为按实际是否发过测试消息提示。
