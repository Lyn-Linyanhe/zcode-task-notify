## 修复

- **给机器人发指令不回话（`40008 invalid message type`）**：企业微信长连接模式**没有 `text` 消息类型**，连"一次性回复"也必须用流式结构 `{"msgtype":"stream","stream":{"id":…,"finish":true,"content":…}}`（SDK 里即 `ws.reply_stream(...)`）。此前「静默 / 恢复 / 状态」能收到（`notify_log.jsonl` 里有 `aibot_cmd`）但回复被退回，现象就是"机器人不理人"。已改用流式回复。
- **结果卡按钮可重复点击**：为绕开 `42045` 必须保持 `card_type=button_interaction`，按钮因此留在结果卡上，可被再次点击。现在 `on_card_click` 做了幂等——同一 `task_id` 只认第一次决定，重复点击只留一条 `decision_dup` 日志，不重复写盘、不重复更新卡片。
