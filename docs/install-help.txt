ZCode 任务通知 · 安装遇到问题？

==============================
 一、没装 Python（最常见）
==============================

这个工具用 Python 写，需要先在电脑上装一次 Python（免费，约 3 分钟）：

  1. 打开 https://www.python.org/downloads/
  2. 点黄色大按钮「Download Python 3.x.x」下载
  3. 双击下载的文件开始安装，**第一屏一定要勾选**
        [✓] Add Python to PATH
     （这一步不勾，装完还是用不了，是最常见的坑）
  4. 装完后，把之前打开的窗口全部关掉，重新双击 install.bat

确认装好了：按 Win+R → 输入 cmd → 回车 → 输入下面这行并回车

     python --version

显示 Python 3.10 以上（例如 Python 3.12.5）就对了。
如果提示"不是内部或外部命令"，说明 PATH 没配好——卸载重装，记得勾选那一项。


==============================
 二、提示 Python 版本太旧
==============================

需要 3.10 或更高。到 https://www.python.org/downloads/ 装一个新版即可，
安装时同样要勾选 "Add Python to PATH"。旧版可以留着不卸。


==============================
 三、还缺什么？
==============================

装好 Python 后，双击 install.bat 会引导你完成剩下的事：
它只需要你粘贴一个「企业微信群机器人 webhook 地址」。

获取这个地址的完整图文步骤在 README 的「第一步」一节（约 5 分钟）：
企业微信手机端 → 群 → 右上角「···」→「消息推送」→ 添加自定义消息推送
→ 创建后复制那一串 https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=...

装完之后，脚本会立刻往群里发一条「🩺 安装成功」——手机上收到就说明通了。


==============================
 四、出问题怎么排查
==============================

在仓库目录里跑：

     python doctor.py

它会做 16 项自检（Python 版本 / 桌面端是否运行 / 开关 / webhook 通道实测 /
hooks 是否正确注册 / 脚本完整性 / 手机批准组件 等），并直接告诉你哪一步不对。

也见 README 的「故障排查」表格。
